# DigitalTwin-Precision

**Hierarchical Edge–Fog–Cloud Patient Digital Twin Framework for Personalized Treatment Optimization**

> Status: Ongoing (final-year project)

## Overview
DigitalTwin-Precision is a patient digital twin framework that uses real-time physiological data from Internet of Medical Things (IoMT) devices to support personalized treatment optimization, while keeping patient data private.

## Key Features
- **Real-time IoMT data ingestion** to build and update a digital twin for each patient
- **Hierarchical Edge–Fog–Cloud architecture** that processes patient data at multiple levels
- **AI and Reinforcement Learning** based treatment recommendation for individual patient profiles
- **Similarity-Weighted Federated Twin Aggregation** for privacy-preserving learning across distributed patient data
